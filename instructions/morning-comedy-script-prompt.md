# Задача: написать 2 комедийных сценария на утренние темы

15.09.2026 → 16.09.2026: по просьбе Ника утренний формат (3 темы/день)
теперь смешанный — **2 из 3 темы делаются в комедийном формате
Совёнка** (тот же мультяшный стиль, что уже вечером — см.
`scripts/social/generate-comedy-short.mjs`), а **третья тема — как
раньше**, обычным форматом (реальный скриншот страницы + начитка сути).
Какая тема какая — решает не агент, а сам рендер-скрипт (он смотрит,
есть ли для темы готовый сценарий в файле, который ты пишешь); твоя
задача — просто написать сценарии для первых двух тем.

## Отличие от вечернего формата

Вечерний формат сам выбирает тему из мягких разделов
(`cifra`/`prava-shkola`/`vospitanie`/…). Утренний формат тему **уже
выбрал** утренний пайплайн (по порядку `TOPICS`, без разбора по
разделам) — тебе не нужно выбирать раздел, только написать сценарий по
теме, которая тебе достанется. Темы утреннего формата охватывают ВСЕ
разделы сайта, включая тяжёлые (травля, развод, подростковые кризисы) —
если тема тяжёлая, веди сценарий как «проблема наступает → ребёнок/
родитель находит правильный ход → проблема отступает», без
искусственного «злодея» и без изображения насилия буквально (через
символ/метафору), твист/payoff обязательно дают реальную надежду и
конкретное действие — те же правила, что уже действуют вечером.

## Шаг 1 — определи 2 темы

Прочитай `scripts/social/posted-youtube.json` (массив уже
опубликованных slug'ов утреннего формата — общий трекер, не зависит от
того, каким стилем видео сделано). Пройди по `TOPICS`
(`content/index.mjs`) в их естественном порядке и найди **первые две**
темы, чей `slug` НЕ входит в `posted-youtube.json`. Именно эти две —
твои темы (третья по порядку неопубликованная тема достанется обычному
формату — ты её не трогаешь).

Прочитай реальный контент каждой темы (`sut`, `ages`, `first`, `steps`,
`law`, `say`, `dont`) — сценарий должен опираться на настоящие факты
темы, не выдумывать новых.

## Шаг 2 — напиши сценарии

Структура каждого — 6 сцен, объект `{ bg, emoji, headline, bubble,
narration, domain? }`:

1. **Интро с маскотом** — `emoji: '🦉'`, `headline: 'Совёнок
   рассказывает'`, `bubble` — короткий тизер темы, `domain:
   'kodeksdetstva.ru'`, `narration`: «Совёнок — герой проекта «Кодекс
   детства» — сегодня показывает [суть темы].»
2. **Проблема заявляет о себе** — злодей (если реально есть
   недобросовестная сторона) или эмодзи-образ ситуации/давления.
3. **Ситуация развивается** — сама проблема в действии, по реальному
   механизму темы.
4. **Твист — ребёнок/родитель находит выход** — конкретная деталь из
   реального `first`/`say`/`steps` темы, не выдумка.
5. **Проблема отступает** — комедийная, но обязательно позитивная
   развязка.
6. **Payoff + сайт** — реальный совет (из `first`/`steps`/`say`) +
   `domain: 'kodeksdetstva.ru'` в бабле + narration: «Совёнок и
   подробный разбор — на сайте кодекс детства точка ру.»

`bg` — CSS `linear-gradient`, тревожный для проблемы / тёплый для
решения (примеры бери из `PILOT` в `generate-comedy-short.mjs`).

## Что НЕ делать

Те же правила, что и у вечернего формата: без реального физического
насилия буквально в кадре, без национальных/этнических/гендерных
стереотипов, не выдумывать факты, не копировать текст темы дословно
(пересказ живым языком), `narration` без цифр цифрами (числа словами),
весь ролик 45-60 секунд озвучки (~110-140 слов на сценарий).

Описание к посту (caption) — как и вечером, собирается автоматически
внутри `renderComedyVideo()` по `slug`, ничего не пиши в
`caption`/`description` сам.

## Куда сохранить

Запиши **массив из двух объектов** (именно массив — не один объект,
как в вечернем формате) в файл
`scripts/social/morning-comedy-scripts.json`:
```json
[
  { "slug": "<slug-темы-1>", "title": "<заголовок, до 90 символов>", "scenes": [ ... 6 объектов ... ] },
  { "slug": "<slug-темы-2>", "title": "<заголовок, до 90 символов>", "scenes": [ ... 6 объектов ... ] }
]
```

Если подходящих неопубликованных тем меньше двух — запиши сколько есть
(даже пустой массив `[]`, если тем нет вообще). Не запускай рендер и не
публикуй сам — это сделает `daily-youtube-post.mjs`. Не трогай
`posted-youtube.json` — его обновляет сам скрипт после публикации.
