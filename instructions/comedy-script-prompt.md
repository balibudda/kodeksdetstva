# Задача: написать сценарий комедийного ролика на новую тему

Ты работаешь в репозитории `kodeksdetstva`. Есть вечерний автопилот
(`daily-comedy-post.mjs`), который каждый вечер публикует один короткий
комедийный ролик в формате «злодей/проблема проигрывает» (в духе Тома и
Джерри) — не пересказ статьи сайта нейтральным голосом, а короткая
сценка с сюжетом, шуткой и твистом, которая всё равно доносит настоящий
совет по правам/безопасности ребёнка. Пилотный ролик (тема «финансовые
ловушки в играх») уже одобрен Ником 14.09.2026 — см. `PILOT` в
`scripts/social/generate-comedy-short.mjs`, он и есть образец
стиля/структуры.

Персонаж-ведущий — **Совёнок 🦉** (свой, отдельный от «Рублёнка» у
kodeksdeneg — там про деньги/мошенников, здесь про детей).

## Шаг 1 — проверь, нужно ли что-то делать

Прочитай `scripts/social/posted-comedy.json` (массив уже опубликованных
slug'ов). **Если файла нет или он пустой** — это первый прогон, ничего
не делай и заверши работу: `daily-comedy-post.mjs` сам возьмёт `PILOT`
из `generate-comedy-short.mjs` по умолчанию.

Если файл не пустой — переходи к шагу 2.

## Шаг 2 — выбери следующую тему

**Важно, отличие от kodeksdeneg**: там ролики специально про самые
болезненные темы (мошенничество), здесь — по прямой просьбе Ника —
**наоборот, шире и мягче**: «другой персонаж — о каких-то тоже больных
но не самых острых темах, лучше позитивное выбирай». Поэтому:

- Приоритет разделов (`content/topics/*.mjs`) — сначала
  **`cifra`** (цифровая безопасность — как у пилота), **`prava-shkola`**
  (права в школе), **`vospitanie`** (воспитание/деньги/доверие),
  **`radost-detstva`** (счастливое детство), **`zdorovie`** (здоровье и
  выбор), **`bezopasnost`** (безопасность вне дома, но без физического
  насилия) — в этом порядке, первая ещё не использованная тема.
- **Избегай по умолчанию** самых тяжёлых разделов — `semya` (насилие в
  семье), `sirotstvo` (детдом/сироты), `pervaya-lyubov` (эмоциональная
  боль), `sryv`/`podrostok-i-zakon`, `razvod` (травмы развода) — бери
  оттуда тему только если все темы приоритетных разделов выше уже
  использованы, и только такую, где `first`/`steps` темы дают реально
  позитивный, обнадёживающий выход (не «жертва осталась жертвой»).
- Внутри выбранного раздела — первая тема по порядку в файле, чей
  `slug` ещё не встречается в `posted-comedy.json` и не совпадает с
  `PILOT.slug`.

Прочитай реальный контент темы (`sut`, `first`, `steps`, `law`, `say`,
`dont`, `ages`) — сценарий должен опираться на настоящие факты темы, не
выдумывать новых.

## Шаг 3 — напиши сценарий

Структура — 6 сцен (как в `PILOT`), каждая — объект
`{ bg, emoji, headline, bubble, narration, domain? }`:

1. **Интро с маскотом** — `emoji: '🦉'`, `headline: 'Совёнок
   рассказывает'`, `bubble` — короткий тизер темы, `domain:
   'kodeksdetstva.ru'`, `narration`: «Совёнок — герой проекта «Кодекс
   детства» — сегодня показывает [суть ситуации].»
2. **Проблема заявляет о себе** — не обязательно злодей-человек (как у
   kodeksdeneg): это может быть игра/приложение/ситуация/давление
   сверстников — эмодзи-образ проблемы (🎮/📱/😰/🎭 и т.п.).
3. **Ситуация развивается** — сама проблема в действии, максимально по
   реальному механизму темы.
4. **Твист — ребёнок/родитель не поддаётся** — конкретная деталь, которая
   решает ситуацию (из реального `first`/`say`/`steps` темы, не
   выдумка).
5. **Проблема отступает** — комедийная, но обязательно позитивная
   развязка, коротко и тепло (не «зло наказано», а «нашли выход
   вместе»).
6. **Payoff + сайт** — реальный совет читателю (из `first`/`steps`/`say`
   темы) + `domain: 'kodeksdetstva.ru'` в бабле + narration заканчивается:
   «Совёнок и подробный разбор — на сайте кодекс детства точка ру.»

`bg` — CSS `linear-gradient` (можно взять готовые примеры из `PILOT`,
меняя оттенок под настроение сцены — тревожный для проблемы,
светлый/тёплый для решения).

## Что НЕ делать — категорически

- Не показывай реальное физическое насилие, не изображай ребёнка как
  жертву без выхода — если тема тяжёлая, показывай ситуацию через
  символ/метафору (не буквальную сцену насилия), а твист/payoff должны
  давать реальную надежду и конкретное действие.
- Не привязывай «проблему» к реальной национальности, этносу, полу,
  профессии реальной группы людей.
- Не выдумывай факты — только то, что реально написано в теме сайта
  (`law`, `sources`).
- Не копируй текст темы дословно в `narration` — перескажи как реплики
  персонажей и рассказчика, живым разговорным языком, коротко (весь
  ролик — 45-60 секунд озвучки, это ~110-140 слов суммарно на все 6
  сцен).
- `narration` пишется для озвучки TTS — простые предложения, без
  сокращений и цифр цифрами (пиши «десять секунд», не «10 секунд» — в
  `bubble`/`headline`, наоборот, цифры можно, это текст на экране, не
  озвучка).

## Описание к посту (caption) — делает сам рендер, не ты

Текст описания под видео (YouTube/Facebook) собирается автоматически
внутри `renderComedyVideo()` (`buildComedyCaption()` в
`generate-comedy-short.mjs`) — он сам подтягивает настоящий контент
темы сайта по `slug`, который ты указал. **Правило проекта (Ник,
14.09.2026): описание должно быть не короче 1000 символов и
уникальным** — это уже гарантировано автоматически, пока `slug` в твоём
сценарии — реальный `slug` темы сайта из `content/topics/*.mjs`. Тебе
НЕ нужно самому писать `caption`/`description` в `comedy-script.json` —
только `slug`, `title`, `scenes`.

## Куда сохранить

Запиши получившийся объект в файл `scripts/social/comedy-script.json` —
**один JSON-объект** вида (не массив — `daily-comedy-post.mjs` читает
файл как один объект и берёт `scriptData.slug` напрямую):
```json
{ "slug": "<slug-темы>", "title": "<короткий цепляющий заголовок для YouTube, до 90 символов>", "scenes": [ ... 6 объектов ... ] }
```

Не запускай рендер и не публикуй сам — это сделает следующий шаг
workflow (`daily-comedy-post.mjs`). Не трогай `posted-comedy.json` — его
обновляет сам скрипт после успешного рендера.
