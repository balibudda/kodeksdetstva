Живой чек-лист. Обновляется по ходу работы.

**Сейчас:** проект называется **«Кодекс детства»**, домен `kodeksdetstva.ru` (утверждён 09.2026, добавлен в Vercel). Сайт: 157 страниц, **135 тем в 13 разделах — все полные, черновиков нет**, 27 федеральных контактов + 17 регионов (у всех есть контакт регионального уполномоченного), отдельная страница `/tebe/` для подростков, онлайн-заполнение заявлений, возрастная маркировка 18+.

## Сделано

### Движок и инфраструктура
- [x] Статический многостраничный генератор без зависимостей (`scripts/build.mjs`): одна проблема — одна HTML-страница со своим URL. Готов к упаковке в Capacitor (`webDir: dist`).
- [x] Полный офлайн: service worker. Переходы между страницами — network-first с тайм-аутом 3 с (свежо при связи, мгновенно из кэша без неё). Статика — cache-first, версионируется `?v=<buildId>` — обновления не «залипают».
- [x] SEO на каждой странице: title, description, canonical, Open Graph, JSON-LD (Article + BreadcrumbList), `sitemap.xml`, `robots.txt`.
- [x] PWA: `manifest.webmanifest` + PNG-иконки (`scripts/gen-icons.mjs`, свой кодек, без зависимостей).
- [x] Клиентский поиск (`assets/search.js`): лёгкий стеммер + словарь синонимов, работает офлайн.
- [x] `api/geo.js` — определение региона по IP через заголовки Vercel. Без внешних запросов и логов. Защита от ботов: лимит 20 запросов/IP за 10 мин → 429, фильтр по User-Agent, приватный кэш 30 мин, вызов не чаще раза на браузер, `Disallow: /api/` в robots.

### Интерфейс

## Монетизация (на перспективу, не ломая бесплатность)

Сейчас проект бесплатный и почти ничего не стоит (Vercel Hobby, бот, пересылка почты). Paywall и платный контент — НЕ вводить, убьёт охват и доверие. Варианты на будущее:

1. **Гранты** — Фонд президентских грантов, региональные гранты, корпоративный CSR (банки, телеком спонсируют детскую тематику). Проект ровно под это подходит.
2. **Донаты** — кнопка «Поддержать проект» (ЮMoney / Boosty / CloudPayments).
3. **Блок «нужен живой юрист / психолог»** с проверенными партнёрами по реферальной модели — не трогая нейтральность текстов тем.
4. **B2B** — методичка / обучение / встроенная версия для школ, соцзащиты, НКО.
5. **Книга-методичка** для родителей на основе контента (печать, маркетплейсы).
