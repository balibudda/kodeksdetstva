# Статус проекта

Живой чек-лист. Обновляется по ходу работы.

**Сейчас:** проект называется **«Кодекс детства»**, домен `kodeksdetstva.ru` (утверждён 09.2026, добавлен в Vercel). Сайт: 127 страниц, **106 тем в 13 разделах — все полные, черновиков нет**, 27 федеральных контактов + 17 регионов (у всех есть контакт регионального уполномоченного), отдельная страница `/tebe/` для подростков, онлайн-заполнение заявлений, возрастная маркировка 18+.

## Сделано

### Движок и инфраструктура
- [x] Статический многостраничный генератор без зависимостей (`scripts/build.mjs`): одна проблема — одна HTML-страница со своим URL. Готов к упаковке в Capacitor (`webDir: dist`).
- [x] Полный офлайн: service worker. Переходы между страницами — network-first с тайм-аутом 3 с (свежо при связи, мгновенно из кэша без неё). Статика — cache-first, версионируется `?v=<buildId>` — обновления не «залипают».
- [x] SEO на каждой странице: title, description, canonical, Open Graph, JSON-LD (Article + BreadcrumbList), `sitemap.xml`, `robots.txt`.
- [x] PWA: `manifest.webmanifest` + PNG-иконки (`scripts/gen-icons.mjs`, свой кодек, без зависимостей).
- [x] Клиентский поиск (`assets/search.js`): лёгкий стеммер + словарь синонимов, работает офлайн.
- [x] `api/geo.js` — определение региона по IP через заголовки Vercel. Без внешних запросов и логов. Защита от ботов: лимит 20 запросов/IP за 10 мин → 429, фильтр по User-Agent, приватный кэш 30 мин, вызов не чаще раза на браузер, `Disallow: /api/` в robots.

Плюс `telegram-web-app.js` в `<head>` (async) и правки CSS `html[data-tg]`.
- [x] **Бот `@kodeksdetstva_bot` запущен.** Вебхук-функция `api/tg.js` (в том же проекте), задеплоена. `/start` (+ deep-link payload), `/help`, фолбэк — везде inline-кнопки `web_app`: открыть приложение, «Помощь сейчас», «Тебе». Кнопка меню бота («Открыть») настроена через `setChatMenuButton`. ## Где что лежит

- `content/sections.mjs` — разделы (id, slug, эмодзи, цвет, порядок, рамка).
- `content/contacts.mjs` — федеральный справочник служб. `content/regions.mjs` — регионы.
- `content/topics/<раздел>.mjs` — темы. Эталон полей (JSDoc `Topic`) — сверху `content/topics/lichnost.mjs`. Раздел «Детдом/сироты» — `sirotstvo.mjs`.
- `scripts/build.mjs` — генератор всех страниц, включая `/tebe/`, `/pomoshch/`, `/regiony/`, `/moe/`, sitemap, sw.js. `scripts/gen-icons.mjs` — иконки. `api/geo.js` — гео по IP.
- `assets/nav.js` — меню, закладки/история/поделиться, регионы, копирование/скачивание `.doc`, **онлайн-заполнение заявлений** (поля по `[...]`, предпросмотр). `assets/search.js` — поиск. `assets/sw.js` — service worker.
- `assets/styles.css` — все стили (темы через CSS-переменные, светлая/тёмная).
- `ANALYSIS.md` — полная карта проблем детства. `CONCEPT.md` — замысел и техплан. `README.md` — архитектура.
- Локальная проверка: `npm run dev` (сборка + сервер на :4321). Деплой — пуш в `main`, Vercel собирает сам.
