# Статус проекта

Живой чек-лист. Обновляется по ходу работы.

**Сейчас:** сайт на Vercel (`childofgod.vercel.app`), 114 страниц, **95 тем в 12 разделах — все полные, черновиков нет**, 27 федеральных контактов + 17 регионов (у всех есть контакт регионального уполномоченного). Домены `childofgod.ru` / `childofgod.app` (название пересматривается — см. ниже).

## Сделано

### Движок и инфраструктура
- [x] Статический многостраничный генератор без зависимостей (`scripts/build.mjs`): одна проблема — одна HTML-страница со своим URL. Готов к упаковке в Capacitor (`webDir: dist`).
- [x] Полный офлайн: service worker. Переходы между страницами — network-first с тайм-аутом 3 с (свежо при связи, мгновенно из кэша без неё). Статика — cache-first, версионируется `?v=<buildId>` — обновления не «залипают».
- [x] SEO на каждой странице: title, description, canonical, Open Graph, JSON-LD (Article + BreadcrumbList), `sitemap.xml`, `robots.txt`.
- [x] PWA: `manifest.webmanifest` + PNG-иконки (`scripts/gen-icons.mjs`, свой кодек, без зависимостей).
- [x] Клиентский поиск (`assets/search.js`): лёгкий стеммер + словарь синонимов, работает офлайн.
- [x] `api/geo.js` — определение региона по IP через заголовки Vercel. Без внешних запросов и логов. Защита от ботов: лимит 20 запросов/IP за 10 мин → 429, фильтр по User-Agent, приватный кэш 30 мин, вызов не чаще раза на браузер, `Disallow: /api/` в robots.

### Интерфейс
- [x] Меню ☰ на каждой странице — все 12 разделов + быстрые ссылки; закрытие по клику вне и Esc.
- [x] Адаптивная вёрстка и шапка (проверено на узких экранах).

- [x] Карточки тем/разделов явно кликабельны: акцентный заголовок, стрелка «›», «… · открыть →», ховер и `:active`.
- [x] Разделы упорядочены «от острого к базовому» (Психика → Безопасность → … → Личность → Воспитание) через поле `order` в `content/sections.mjs`.

## Название (за Ником)

Отзыв Елены Соколовой: «Дитя Бога» рискованно — не все одинаково относятся к слову «Бог»; хочется более «рабочий» вариант, позитивный, можно с лёгким юмором. Ник решил взять новое название без «Бога» и, если нужно, купить новый домен. Кандидаты (серьёзное направление, `.ru` свободны):
- **Право на детство** (pravo-na-detstvo.ru) — авторитетно + эмоционально; у каждого ребёнка есть право на детство без насилия и страха.
- **Право ребёнка** (pravorebenka.ru) — прямо, под поиск.
- **Кодекс детства** (kodeksdetstva.ru) — самое «мощное» звучание, брендовое.
- Ещё: Детское право, Дети и закон, Защита детства, Щит детства, Оберег, Взрослый рядом, Твоя сторона, Навигатор родителя, Маяк.
- После выбора: переименовать `SITE.name` и все тексты/фавикон, привязать новый домен, обновить `repo`/Vercel по желанию.

## Где что лежит

- `content/sections.mjs` — разделы (id, slug, эмодзи, цвет, порядок, рамка).
- `content/contacts.mjs` — федеральный справочник служб. `content/regions.mjs` — регионы.
- `content/topics/<раздел>.mjs` — темы. Эталон полей — `content/topics/lichnost.mjs` (JSDoc сверху).
- `scripts/build.mjs` — генератор. `scripts/gen-icons.mjs` — иконки. `api/geo.js` — гео по IP.
- `assets/` — CSS, поиск, service worker, JS (меню, закладки, регионы, копирование/скачивание документов).
- `ANALYSIS.md` — полная карта проблем детства. `CONCEPT.md` — замысел и техплан.
