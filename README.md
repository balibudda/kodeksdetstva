# Дитя Бога

Справочник для родителей: права ребёнка простым языком, защита от домашнего
насилия и школьной травли, безопасность вне дома (включая похищение), цифровые
угрозы, психика и кризисы, здоровье и закон. С опорой на закон и на уважение к
ребёнку как к личности.

**Принцип:** одна проблема — одна HTML-страница со своим точным URL. Всё
статическое, работает офлайн, готово к упаковке в приложение (Capacitor → APK/iOS).

Самостоятельный проект. Не имеет общего кода, окружения или инфраструктуры с
другими репозиториями.

## Архитектура

- Контент — структурированные данные в `content/` (не в разметке):
  - `content/sections.mjs` — разделы верхнего уровня
  - `content/contacts.mjs` — единая база служб и горячих линий (телефоны → `tel:`,
    почта → `mailto:`, сайты ведомств → внешние ссылки)
  - `content/topics/*.mjs` — темы-ситуации, по файлу на раздел
  - `content/index.mjs` — сборка + проверки целостности
- `scripts/build.mjs` — генератор: рендерит по HTML-странице на каждую тему,
  раздел и служебную страницу в `dist/`, плюс `sitemap.xml`, `robots.txt`,
  `manifest.webmanifest`, `search-index.json`, `sw.js` (офлайн), `404.html`.
- `assets/` — общий CSS, клиентский поиск, service worker, мелкий JS (копирование
  шаблонов документов).

Каждая страница: полноценное SEO (title, description, canonical, Open Graph,
JSON-LD Article + BreadcrumbList), тема оформления под светлую и тёмную.

## Структура темы

`content/topics/lichnost.mjs` — эталон полей. Каждая карточка:

- `🚩 redFlags` — красные флаги: если это есть, дальше может быть очень плохо;
- `sut` — что происходит;
- `📌 first` — что сделать в первую очередь;
- `⚖️ law` + `📖 lawQuotes` — что говорит закон и дословные цитаты, чтобы сослаться;
- `✅ steps`, `🗣 say`, `⛔ dont`;
- `📄 templates` — готовые тексты заявлений и жалоб;
- `📞 contacts` — id из базы контактов, рендерятся кликабельными;
- `📚 sources`, `related`.

Статусы: `full` — полный разбор, `planned` — краткий разбор, дополняется
(формулировки о законе проходят проверку).

## Разработка

```bash
npm run build     # -> dist/
npm run serve     # http://localhost:4321 (после build)
npm run dev       # build + serve
```

Зависимостей нет. Нужен Node 20+.
