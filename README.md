# Дитя Бога

Приложение для родителей: права ребёнка простым языком, защита от домашнего
насилия и школьной травли, осознанные решения о здоровье, помощь в подростковых
кризисах. С опорой на закон и на уважение к ребёнку как к личности.

Самостоятельный проект. Не имеет общего кода, окружения или инфраструктуры с
другими репозиториями.

## Стек

- Vite + React 19 + TypeScript
- `vite-plugin-pwa` — offline-first PWA
- Позже: обёртка в APK / iOS через Capacitor (ассеты бандлятся в приложение,
  без `server.url`, работает офлайн и не выглядит как сайт в webview)

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # -> dist/
npm run preview
```
